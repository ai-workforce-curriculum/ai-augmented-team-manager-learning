## Module layout

Each `mod-XXX-name/` directory ships the same shape:

- `README.md` — module overview, learning objectives, chapter and exercise index, and the "where this fits" map.
- `01-….md` … `0N-….md` — lecture chapters in reading order.
- `exercises/` — per-exercise prompts; solutions live in the sibling [`ai-augmented-team-manager-solutions`](https://github.com/ai-workforce-curriculum/ai-augmented-team-manager-solutions) repo.
- `labs/` — long-form hands-on labs (scaffolded; authored in subsequent cycles).
- `quizzes/` — knowledge checks (scaffolded; authored in subsequent cycles).
- `resources.md` — curated primary-source reading for the module.

## How to read the track

The track is sequenced: `mod-101` sets the role, contract, and deferral rubric that every later module references; `mod-102` turns that into the adoption roadmap; `mod-103`–`mod-106` build the team's day-to-day operating system (review standards, measurement, enablement, workflow redesign); `mod-107`–`mod-109` handle the people and accountability layers; `mod-110`–`mod-112` cover governance translation, vendor selection, and the cross-functional ritual and communication calendar that ties the whole thing together. Each module's "Where this fits in the track" section names its forward and back links.
