# Exercise 02 — Manager-Output Fundamentals Self-Audit

**Estimated effort:** 2 hours.

## Objective

Self-audit your current manager-output fluency against the four canonical texts (Grove, Fournier, Larson, Zhuo) that Chapter 2 declares as the assumed baseline, and produce a short reading / practice plan for any gap. The goal is not to re-read all four books in two hours — it is to find the gaps that will make the rest of this track harder if left unaddressed, and to put a specific, dated remediation on the calendar.

## Prerequisites

- Chapter 2 of this module.
- The [`PREREQUISITES.md`](../../../PREREQUISITES.md) *Recommended reading before starting* section.
- Whatever notes, highlights, or prior reading you have on the four texts. If you have read none of them, that is a valid starting state; the exercise is about calibrating the gap, not pretending to have closed it already.

## Steps

1. **Rate yourself on the six ideas from Chapter 2.** For each of the six ideas below, write one sentence on where you stand: *fluent (I use this concept weekly in how I actually manage) · familiar (I recognise it and could re-read the chapter and apply it) · new (this is unfamiliar)*.
   1. Grove's output model and leverage.
   2. Grove's task-relevant maturity and situational delegation.
   3. Fournier's line-manager playbook (1:1s, feedback, hiring, running a project).
   4. Larson's team-sizing heuristics and the systems view of recurring work.
   5. Zhuo's trust-as-substrate framing.
   6. Zhuo's useful-feedback framework (specific / timely / kind / actionable).
2. **Rate yourself on five day-to-day practices.** For each: *strong / adequate / weak / not-yet-doing*.
   1. Running regular 1:1s with a documented cadence.
   2. Giving feedback close to the event, with a repeatable structure.
   3. Owning a hiring loop end-to-end (job description, interview plan, debrief).
   4. Running a quarterly planning cycle you can describe without hedging.
   5. Owning a team budget large enough to include tool / vendor choices.
6. **Map the gaps.** Pull every "weak / not-yet-doing" and every "new" rating into one short table. For each row, name the specific text (and chapter if you can) that covers it, and the mod in this track where it will come up again.
7. **Write the plan.** Three columns: *gap / remediation / date*. Dates must be real calendar dates in the next 90 days. Remediations should be concrete ("read Fournier chapters 3–5 by 2026-12-01, and run a 1:1 using the framework on 2026-12-02") rather than aspirational ("get better at 1:1s").

## Starter guidance

- This is a private artifact. Honesty beats polish. A plan that admits two real gaps is more useful than a plan that lists six minor ones to look diligent.
- If you rate yourself *fluent* on everything, verify: pick one idea at random and write a paragraph explaining it to a hypothetical direct report. If the paragraph is wobbly, downgrade.
- Pair with a manager peer or your own manager if feasible — a five-minute sanity check will catch the ratings that are too generous.
- If you have never run a hiring loop or owned a team budget, this track is still usable but `mod-108` and `mod-111` will land harder. Flag that now.

## Acceptance criteria

The audit is complete when:

- All six Chapter 2 ideas have a *fluent / familiar / new* rating.
- All five day-to-day practices have a *strong / adequate / weak / not-yet-doing* rating.
- Every "weak," "not-yet-doing," and "new" rating appears in the gap table with a text reference and the module where it reappears.
- The remediation plan has real dates in the next 90 days.
- The whole artifact is one or two pages — long enough to be honest, short enough that you will actually revisit it.

## Stretch goals

- Bring the plan to your next 1:1 with your own manager; confirm one gap and one remediation with them.
- Pick one "familiar" idea and upgrade it to "fluent" over a 30-day window by applying it deliberately in one recurring practice (1:1s, feedback, planning). Write a short note on what changed.
- If you have read all four texts already, pull a **second-layer** reading for one of the gaps — e.g., Edmondson *The Fearless Organization* alongside Zhuo on trust — and add it to the plan.
