# Labs for mod-101-ai-augmented-team-manager-position-and-contract (The AI-Augmented Team Manager: Role, Scope, and the Human/Machine Contract)

Guided hands-on sessions. Each lab calibrates against a specific chapter using a fixed input (a curated ask-set, a broken sample contract, a disposable repo) so you can test your reading against a known answer before running the corresponding exercise on live inputs.

- [Lab 01 — Routing Drill: Twelve Asks Through the Rubric](lab-01-routing-drill-twelve-asks.md) (60–75 min) — run twelve curated asks through the Chapter 4 rubric with an answer key; calibration before Exercise 04.
- [Lab 02 — Contract Gap-Finding on a Broken Sample](lab-02-contract-gap-finding.md) (60 min) — grade a deliberately broken sample contract against Chapter 3's C1–C5 and rewrite the accountability stack; calibration before Exercise 03.
- [Lab 03 — Fluency-Floor Sanity Check](lab-03-fluency-floor-sanity-check.md) (45–75 min) — run Chapter 5's weekly rhythm end-to-end on a disposable repo and produce an evidence-grounded self-rating; calibration before Exercise 05.
