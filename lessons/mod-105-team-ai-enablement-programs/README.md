# mod-105-team-ai-enablement-programs: Team-Level AI Enablement Programs

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 14 hours

## Learning objectives

- Design a team-scope AI enablement program — Day 0 / 30 / 60 / 90 structure for a 5-30 person team, running internal bootcamps, workshops, communities of practice — anchored in R5 (0.36, 4 in-window postings)
- Pick and distribute tool budgets (Cursor seats, Copilot seats, token allowances) in a way that mirrors learning stage, not seniority alone
- Measure fluency growth with practical artifacts (first-successful-PR-with-tool, pair-with-agent-reflection, review-of-your-review) grounded in Josh Bersin AI-in-L&D research and Microsoft Work Trend Index data
- Partner with HR / L&D / Platform on the delivery side; know when a program needs to graduate to org-wide ownership at `ai-enablement-lead` (level 45)
- Build on mod-101's manager-fluency bar — the manager doesn't deliver every workshop but authors the curriculum and sets the measurement rubric

## Structure

- `01-…md` … `0N-…md`: lecture chapters.
- `exercises/`: per-exercise prompts.
- `labs/`: long-form hands-on labs.
- `quizzes/`: knowledge checks.
- `resources.md`: external references.
