# Labs for mod-106-workflow-redesign-and-agent-delegation (Workflow Redesign and Agent Delegation at Team Scope)

Guided hands-on sessions. Each lab calibrates against specific chapters using a fixed input (a curated task set, a deliberately broken HITL spec set, a curated MCP server catalogue) so you can test your reading against a known answer before running the corresponding exercise on your own team.

- [Lab 01 — Routing Matrix on a Curated Sample Team](lab-01-routing-matrix-on-a-curated-team.md) (60–75 min) — place ten curated task types for a fictional internal-tools team against Chapter 2's three-question placement and the five destinations, with an answer key that includes contested rows; calibration before Exercise 01.
- [Lab 02 — HITL Checkpoint Red-Team on a Broken Sample](lab-02-hitl-checkpoint-red-team.md) (60 min) — diagnose four deliberately broken HITL checkpoints against Chapter 4's five-field spec and four failure modes, and rewrite each with a ladder-consistency check; calibration before Exercise 04.
- [Lab 03 — Tool-Authorisation Band Sorting on a Curated MCP Surface](lab-03-tool-authorisation-band-sorting.md) (60–75 min) — classify sixteen tools across three MCP servers and one A2A agent card into Chapter 6's four bands, re-sort under the untrusted-input invariant, and pick the right incident route on three attempted calls; calibration before Exercise 03.
